# AS Barbershop preview

1. Kreiraj novi GitHub repo, npr. `as-barbershop-preview`.
2. Uploaduj `index.html` u root repozitorija.
3. Na Vercelu: Add New → Project → Import repo → Framework: Other → Deploy.
4. Pošalji live link potencijalnom klijentu.

Napomena: cijene i informacije su uzete iz javno dostupnog AS Barbershop/Fresha profila i služe kao prodajni preview. Aktuelne cijene i termini trebaju ostati vezani za njihov Fresha sistem.
